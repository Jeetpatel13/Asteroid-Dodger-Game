# Asteroid Dodger

A simple C# Windows Forms game. Move the ship left and right with the arrow keys
and dodge the falling asteroids.

## Features
- Randomly generated asteroid field
- Custom-drawn ship using GDI+ shapes
- Scoreboard showing time, dodged asteroids and hits
- 60 FPS animation with a timer and double buffering

## Controls
- Left arrow: move left
- Right arrow: move right

## Requirements
- Visual Studio with the .NET desktop development workload
